# Enock Kibet Portfolio

A modern personal portfolio site built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- Responsive portfolio layout
- About, skills, projects, and contact sections
- Animated hero details and scroll-reveal effects
- Project cards with modal previews
- Built for deployment on GitHub Pages

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deployment

This project is ready to be deployed on Vercel using the default Vite build settings.
